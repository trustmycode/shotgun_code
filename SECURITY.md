# Безопасность

Не публикуйте сведения об уязвимостях в открытых задачах. Отправьте приватное сообщение владельцу репозитория через раздел «Безопасность» GitHub и укажите затронутую версию, способ воспроизведения и возможное влияние.

Ключи поставщиков моделей хранятся локально в каталоге настроек Shotgun Code. Файлы настроек и истории создаются с правами `0600`, однако их содержимое не шифруется. Не используйте общий профиль операционной системы и очищайте историю после работы с чувствительным исходным кодом.

Перед отправкой контекста проверьте выбранного поставщика, пользовательский базовый адрес и перечень файлов. Пользовательский адрес разрешён только по HTTPS, но получает тот же ключ и исходный код, что и официальный адрес поставщика.
